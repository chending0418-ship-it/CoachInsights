## 二、目标操作流程

- **打开和观看**：资料库点视频封面 → 原比例视频立即进入观看页 → 底部播放 / 暂停、前后帧、倍速、循环始终可用。已有记录从上次位置恢复；新视频默认 1×，用户调整后的倍速按素材保存。
- **定位和绘图**：进度条快速找位置 → 刻度带或前后帧精调 → 点绘图暂停并确认当前帧 → 展开侧边工具 → 绘制 / 撤销 → 收起工具继续看。进入人体分析直接打开设置，不经过订阅页。
- **双视频对比**：当前视频点对比 → 从本机资料库 / 相册 / 文件选第二段 → iPhone 竖屏默认上下布局，宽屏默认左右布局 → 独立定位并设置同步点 → 联动播放。取消选片回到原视频与原位置。
- **退出与分享**：截图快捷入口导出当前帧；更多菜单进入片段导出。关闭工具只关闭工具，退出对比返回原单视频，退出观看返回原资料库位置；编辑状态自动保存。

## 四、Smooth 的测试口径与目标

以下为本次规划提出的验收目标，**尚未测量或证明达到**。V101-004 先采集 1.0 基线，V101-020 再对照。若素材或模拟器环境导致目标不适用，必须记录原因、实测值和替代标准，不能静默降低门槛或表述成已优化。

统一使用现有 iPhone、iPad 项目专用模拟器，固定同一 Mac、系统版本和 Release 构建条件，避免并行分析 / 导出干扰。缓存冷 / 暖分别测；暖为同一会话和邻近帧缓存命中，冷为相关缓存清空后的首次访问。素材首次复制和元数据扫描单列，不混入已导入素材打开耗时。模拟器结果用于可复现回归，不代表真机能耗、发热或触控性能。

| 项目 | 本轮目标 | 计量方式 |
| --- | --- | --- |
| 常用控制反馈 | 点击后 100ms 内出现按下 / 加载 / 状态反馈 | UI 时间戳与录屏核对；不能用按钮变色代替实际播放完成 |
| 已导入素材打开 | 暖打开首个可见正确帧 p95 ≤1s；冷打开 ≤3s | 每类至少 20 次；从点封面到可见正确画面，记录错误与超时 |
| 连续逐帧 | 暖缓存 p95 ≤150ms；1080p 未命中 p95 ≤500ms；4K ≤1s | 每类至少 100 次，从操作到最终正确帧；前后方向分开记录，长按需测松手停止 |
| 拖动落帧 | 松手后 1080p p95 ≤500ms；4K ≤1s | 每类至少 30 轮；包含高速往返、边界与中途播放，精确帧必须正确 |
| 播放 / 暂停 | 暖状态 p95 ≤300ms；启动较慢时及时显示加载 | 各至少 30 次，测画面实际推进 / 停止，不能只看 `playing` 布尔值 |
| 倍速 / 循环 | 无可见黑闪、回跳或停死；变速不触发不必要的重新加载 | 五档速度，至少 20 次循环；记录接缝耗时、最大值与异常录屏，不承诺未经测量的无缝循环 |
| 双路同步 | 保持原 1.0 标准：精确定位各路误差不超过该位置一个源帧间隔；连续 / 循环无累计漂移 | 不同帧率和时长，至少连续运行 60s 或循环 20 次；分别记录时钟差、可见画面差及校正次数 |
| 资源与叠加开销 | 缓存遵守现有有界预算，内存警告后可回收；开关骨架后仍满足上述交互目标 | 各场景连续操作 10 分钟，采样完整进程内存和各缓存，双路单列；沿用原资源回归门槛 |

素材矩阵：横 / 竖视频、1080p / 4K、30 / 60 / 120 / 240fps、可变帧率、相册慢动作、短动作片段 / 1–5 分钟素材，双路包含不同帧率 / 长度。使用真实存在的样本标记覆盖，不要求所有尺寸与帧率做笛卡尔积。已有高帧率和慢动作映射、原片保护、导出一致性与辅助估算提示继续作为功能门禁。
