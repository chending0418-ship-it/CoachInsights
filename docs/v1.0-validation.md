# Coach Insights 1.0 开发与模拟器验收

日期：2026-10-22。分支：`codex/1.0-development`；不合并 main。

## 本轮实现

| 模块 | 代码入口 | 已接入的行为 |
| --- | --- | --- |
| 拍摄、文件和相册 | CaptureService、CaptureView、PhotoImportView、LibraryRepository | 能力检测、按格式枚举帧率、可选录音、拒绝权限降级、回看、本机复制、进度、取消、失败重试 |
| 单视频 | AnalysisWorkspace、SessionDetail、PlaybackCoordinator | 实际 PTS 逐帧、精确定位、五档速度、循环、片段、静音、缩略图、命名关键帧、缩放平移镜像旋转 |
| 标注 | AnalysisCanvas、AnalysisRenderer | 直线、箭头、椭圆、手绘、文字、三点角；颜色线宽、选择移动及控制点编辑、删除、撤销重做、单帧或片段可见性 |
| 双视频 | ComparisonWorkspace、ComparisonView | 两路选择及替换、布局、各路画面与片段、同步点和偏移、共同区间、共享主机时钟、漂移检查、保存重开 |
| 人体姿态 | PoseEngine、PoseToolsView | 模拟器原生 Full / iOS Vision 优先回退、离线逐帧、区域选择、进度取消、重试复用、逐路配置、置信门限、骨架和二维角度 |
| 导出 | ExportService、ExportView | 当前素材截图、慢放片段、双路合成、H.264 / SDR / 30fps、1× 可选原声、取消清理、系统分享与保存相册 |
| 说明与隐私 | HelpView、PrivacyInfo.xcprivacy | 操作说明、权限用途、本机存储和删除语义、开源许可、文件元数据与磁盘空间使用原因 |

记录自动保存，包含矢量标注、片段、关键帧、播放位置、单视频速度、逐路姿态参数和比较设置。旧版 1.0 快照缺少新增字段时使用默认值读取；无效坐标和未知版本不能覆盖已保存记录。导出只写新文件，不修改原片。

## 验证环境与范围

- Apple Silicon Mac、Xcode 26.1.1（17B100）、iOS 26.1（23B86）。
- iPhone 16e、iPad mini（A17 Pro）项目专用模拟器；App 部署目标 iOS / iPadOS 17+。
- MediaPipe Tasks 1.1.1 实际分发包仅带 arm64 模拟器切片，工程显式排除 x86_64；CI 固定使用 arm64 `macos-26` runner。
- 按用户要求不做真机验证。模拟器没有相机，以能力检测、权限适配器、AVFoundation 代码编译和可替换录制输入验证拍摄闭环，不将此称为真实摄像头采集验收。

## 关键自动化覆盖

1. 30 / 60 / 120 / 240fps、VFR、方向、慢动作源 / 展示映射；保存原片与映射后重新构建本机 AVComposition，120 个源帧仍可逐帧定位。
2. 播放暂停冻结 AVPlayer 当前帧，循环关闭时停在区间末帧并可重新播放，开启时回到起点；单路与双路均验证。快速连续 seek 只显示最终帧；片段终点为排他边界，不能前进到区间外下一帧；播放和导出在 VFR 间隔内保持上一帧，不能使用最近帧而提前切到未来帧。旧取消请求不能干扰共享播放准备。
3. 标注帧范围、三点角度、所有绘图工具和四向旋转；选择标注恢复其颜色、线宽和文字，撤销重做保留对应样式；相同坐标规则用于预览、截图与视频。导出解码后核查叠加位置和两路不同源时间的颜色标记。
4. 不同帧率 / 长度的同步、区间边界、共享时钟实际推进与漂移、布局及同步点重开恢复。
5. 原生 Full 实际运行于用户 4K 打击片段；模拟输入无人体时留空。覆盖取消、重试、显示开关复用和分析区域改变失效。
6. 实际生成 10-bit HEVC / HLG 源片，导出为 H.264 / Rec.709 SDR 并核查亮暗对比；生成带音轨源片，核查 1× 原声、慢放静音和时长。
7. 存储不足、缺片、重关联、中断 staging、共享引用删除、缓存压力及损坏缓存、旧快照迁移、相机 / 麦克风拒绝后的导入与无声降级。
8. 两端 UI 实际调用系统相册选择本机视频，覆盖授权弹窗、导入、触控标注、撤销重做、命名关键帧、横竖屏、人体分析、保存重开、截图导出、系统分享面板打开与关闭、模拟录制回看和双路对比。iPad 另验证 360pt 窄窗口及恢复宽窗口。

2026-10-22 最终全量回归：每端 34 项核心测试、6 项 UI 测试；共 79 项通过、0 失败、1 项按设备跳过（iPhone 不执行 iPad 窗口专用场景）。相册用例两端均实际执行，未跳过。

## 人体质量门禁

[姿态引擎与样本记录](pose-engine-validation.md)、[数值文件](pose-quality-metrics.json) 保存独立 60 帧的人工坐标对照。Full 与 Heavy 均未达到原计划 90% PCK@0.05 门槛。V1-048 及依赖该质量门禁的最终交付确认保留未完成；没有将检出帧数、模型置信度或模拟器运行成功等同于精度通过。

## 构建与本机证据

```sh
python3 scripts/verify.py
python3 scripts/build_simulator_release.py --install
```

构建脚本先下载并校验 Full 模型，再生成工程；SPM 根据已固定的 URL / SHA-256 取得原生二进制。下载发生在开发构建阶段，安装后的 App 离线运行。没有账号、上传 API 或 iCloud capability；SwiftData 显式 `.none`，资料目录排除系统备份。

Release 编译已同时通过 arm64 模拟器目标和通用 iOS 目标（关闭签名，仅编译，不运行真机）。模拟器 Universal App 为 1.0 (1)、最低系统 17.0，包大小约 54.69MiB；核查包含 Full 模型、隐私清单与已确认图标，不含测试视频、Heavy 或 XCTest。

Release 已安装并启动于项目专用 iPhone 16e、iPad mini A17 Pro 模拟器；界面不带 Debug 诊断或模拟录制入口，UI 测试资料库与正常使用资料库隔离。

日志和结果：`artifacts/iphone/V1.xcresult`、`artifacts/ipad/V1.xcresult`；Release：`build/ReleaseV1/Build/Products/Release-iphonesimulator/CoachInsights.app`。测试帧、录像、模型和 xcresult 均被 Git 忽略，Release 不含 XCTest、私有测试素材、诊断入口或 Heavy 模型。

权限清单使用磁盘空间 E174.1 与文件元数据 C617.1 / 3B52.1，依据 [Apple required-reason API 文档](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitype)。CI runner 体系依据 [GitHub runner 参考](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)。实际云端 CI 状态以 GitHub Actions 运行为准。
