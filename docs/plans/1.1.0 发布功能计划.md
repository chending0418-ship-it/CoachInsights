# 棒球训练助手 iOS 1.1.0 发布功能计划

## 1.1.0（Build 13）视频分析与动作对比

本次修复覆盖共享拖动预览、逐帧落点、带 B 帧的视频导入、自动布局重开、带筛选条件新建记录和同屏导出。校验覆盖 iPhone 与横屏 iPad 的实际操作、不同帧率及可变帧率、同步点、截图和成片。 Build 13 同一轮定位期间，iPhone 两路分别换帧 22、21 次，iPad 为 29、28 次；两端松手至精确落帧均约 0.19 秒。这些测量来自模拟器。 人体区域选择与播放页共用视频画布，选择区域和识别骨架可以叠在同一帧上。 本机[复测记录](../../artifacts/validation/1.1.0-13-video/index.html)与[签名归档目录](../../artifacts/releases/1.1.0-13/)按构建号保存。TestFlight 由用户上传。

版本适用 iPhone 和 iPad。Build 9 已整合双站位投球记录、好球率和逐球修正回看，以及个人计划、教练笔记、练习卡、团训和分段计时。Build 10 补齐原生页面，沿用既有本机记录和数据格式。

| 功能组 | 本次界面与操作 |
| --- | --- |
| 入口与记录 | 正确浅底产品字标、三场景入口、宽屏侧栏与最近记录、按场景显示相关记录、记录摘要、可展开的帮助问题与独立隐私页 |
| 场边训练 | 深绿比分牌（局数、双位数及 B/S/O 灯位）、打击四类轨迹与总挥棒数、双端历史轮次与本轮过程、投球五项指标与按站位记球、秒表分段与刻度表盘、倒计时表盘与快捷时长、测距可用与不可用状态、原版战术白板 |
| 视频与对比 | 素材库、新建、导入与拍摄、动作画布与工具、关键帧跳转、人体范围设置、片段调整、对比选择与布局、导出设置和结果 |
| 教练内容 | 个人计划、教练笔记、练习卡、团训计划的列表、填写与预览。宽屏并排，紧凑屏切换。图片分享与分段计时 |
| 验证 | 以 A 稿 46 条为入口。45 条对应 App 状态，页面目录仅用于设计评审。实机相机采集及 AR 精度另验。归档及 TestFlight 交付状态以 CURRENT 为准 |

| 范围 | 本次改动 |

### Build 12 原生页面

以已定稿的 46 个设计条目为目录，其中 45 个对应产品页面或操作状态。页面目录用于浏览设计。iPhone 与 iPad 在同一套训练样例下通过真实入口逐项取图，白板对照旧版横屏球场。覆盖训练记录、投打与比赛、四类教练资料及其编辑预览、选片、绘图、人体选区、片段与导出。核对图保存在本机 artifacts/validation/1.1.0-12-a。模拟器可核对相机和测距的设备不可用状态，实拍与 AR 测距需设备验证。

两端独立图像审核与专项整改已记录在[Build 12 验收说明](../validation/v1.1.0-build12-page-review.md)。
