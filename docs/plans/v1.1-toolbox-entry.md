# 棒球训练助手 1.1：场景入口与导航

2026-11-05 命名更新：产品现名为棒球训练助手 / Drill Buddy，面向教练、家长和球员；本轮保留既有模块编号与导航，入口用语后续评审。

2026-10-22，依据用户在 1.1 讨论中确认的工具范围与入口布局实施。本阶段先接入入口，各工具内容由用户后续逐项评审；工程名、Bundle ID 和 `Config/Build.xcconfig` 的 1.0.1（4）保持不变。

逐项讨论与实施使用 [1.1 功能与模块 TODO](v1.1-todo.md)，各工具有固定编号；本文继续记录已确认的入口方案与兼容约束。

## 本阶段范围

- 首屏为三个场景大卡片：上方“私教／团训”等宽等高，下方“随手工具”通栏，左右边线、横纵间距统一。iPhone、iPad 使用相同层级。
- 场景卡片 → 场景工具列表 → 独立操作页 → 结果／分享；每层可逐级返回。
- 底部保留“工具箱／记录”。操作页隐藏底部入口，使视频工作区保持完整空间；两个主入口分别保留导航和筛选状态。
- 记录支持来源场景与具体工具类型联合筛选。切换来源时清除不兼容的工具筛选；打开记录再返回保留筛选条件。
- 视频分析与动作对比连接既有本机素材、导入、分析和对比流程；入口阶段其他 12 个工具只建立独立页面。后续 Q01–Q04 及 00 期 T03–T05 已接入实际内容，其余 5 个保留“内容待完善”，详见 [模块 TODO](v1.1-todo.md)。

## 2026-11-06 的 00 期导航细化

宽度至少 900pt 时使用按私教、团训、随手工具分节的工作室侧栏；侧栏可以收起或展开，白板自动隐藏侧栏保留完整画布。窄窗口使用原紧凑层级和底部工具箱／记录，工具操作页隐藏底栏。打击／投球／模拟比赛均接入统一记录；团训的白板与模拟比赛行显示完整摘要。Debug 图片卡片示例纳入明确路由，进入后隐藏底栏，避免覆盖生成与分享操作。

三种计数的本机数据独立保存到 `field-tools-v1.json`，既有视频与其他工具不改格式；历史可按场景及工具筛选、打开、继续编辑、确认删除。

## 确认的工具清单

| 场景 | 工具 |
| --- | --- |
| 私教 | 视频分析、动作对比、个人训练计划、教练笔记、课后练习卡 |
| 团训 | 训练计划、按计划计时、简单比赛计数器、战术白板 |
| 随手工具 | 秒表、倒计时、打击简单记录、投球简单记录、测距 |

后续工具内容的确认约束：

- 个人训练计划、教练笔记可自行填写，并生成分享卡片。
- 课后练习卡支持快速填写；上述三类内容均需要图片卡片与在线链接。链接发布在本阶段没有接入线上服务。
- 团训计时跟随训练计划；打击记录以滚地、高飞等简单计数为主；牛棚记录好球、坏球、出局数与总球数；比赛计数器保留出局数、当前好坏球。
- 战术白板使用棒球场底图，支持随手绘制；测距方式与精度在该工具后续设计时验证。

## 现有资料兼容

不变更 SwiftData 模型或已保存的 `SessionSnapshot`。现有分析资料通过只读适配接入记录页：保存有双视频对比设置的记录显示为“私教 · 动作对比”，其余显示为“私教 · 视频分析”。列表只提取记录摘要，不展开每帧人体结果；选择记录时恢复相应的既有操作页。

记录行使用值快照，不保留可失效的数据库对象作为展示数据；删除前先撤下界面引用，失败时重新读取原有列表。两个主入口只加载当前界面，导航路径和筛选由外层保留，避免隐藏页面继续读取已删除资料。

入口阶段为团训和随手工具提供筛选与空状态；白板草稿现归团训记录，主动保存的测距结果归随手工具记录，使用独立的本机 JSON 存储，不变更视频 SwiftData 模型。不创建示例业务记录，不将讨论草案中的演示计数或链接发布标成已实现能力。

- `CoachInsights/Features/Toolbox/`：场景／工具目录、首页、工具列表、占位页及记录筛选。
- `CoachInsights/Features/Library/VideoLibraryView.swift`：原素材库接入独立导航层级；分析和对比入口共用本机素材流程。
- `CoachInsightsTests/ToolboxTests.swift`：旧记录只读兼容、视频／对比分类、切换场景后的筛选一致性。
- `CoachInsightsUITests/CoachInsightsUITests.swift`：首屏对齐、场景逐级导航、记录联合筛选与返回恢复；原视频流程测试改从新入口进入。
