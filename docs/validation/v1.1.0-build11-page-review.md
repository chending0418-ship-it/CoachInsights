# 1.1.0（11）原生页面复核

依据 A「场边速记」逐项复核 iPhone 和 iPad。每端 45 项，包括 42 项可在模拟器比对的 A 稿界面、1 项经典白板，以及 2 项需要真实相机或 ARKit 的状态。核对主信息、操作入口和宽屏分栏。每项结论可在本机[逐页对照图](../../artifacts/validation/1.1.0-11-a/index.html)切换原稿、Build 10 和 Build 11。

截图使用 iPhone 17 Pro 竖屏和 iPad Pro 11 英寸横屏，手机白板按产品要求横屏。独立页面取样使用真实 SwiftUI 视图、本机存储和公开棒球素材，部分图未包含外层导航；完整操作另用 UI 回归覆盖。真实摄像头、录制及实景测距仍须真机复核。

## 视频与对比

| 页面 | iPhone | iPad 横屏 |
| --- | --- | --- |
| 视频资料库 | 搜索、视频／分析切换、运动与日期分别可见；素材采用双列缩略图。 | 双列缩略图或分析列表在左，相册、文件、拍摄及新建集中在右。 |
| 新建分析 | 名称、运动、惯用手和角度按顺序填写，创建操作位于表单下方。 | 输入区和记录说明、创建操作分栏。 |
| 导入素材 | 系统选择器负责选择文件；确认页显示所选真实视频预览、运动类型和打开并分析。 | 所选真实素材的预览与导入选项左右并排。 |
| 拍摄素材 | 验证了相机不可用提示及重试入口；真实取景、录制和确认待真机。 | 横屏按取景区与控制区分栏，已检查不可用分支；真实取景仍待设备。 |
| 视频分析 | 画布和逐帧播放控制下并列绘图、关键帧、人体和修剪。另有截图、对比与导出操作。 | 视频、播放和四个编辑入口组成主区；相关动作与节点列表在右栏。 |
| 绘图标注 | 绘图工具图标配有名称，颜色和单帧／片段范围直接可选，支持撤销。 | 当前画布与工具面板并排；颜色与范围在面板内直接可选。 |
| 关键帧 | 命名、保存、节点列表与真实视频同页，选节点后可确认画面。 | 视频和播放在左，命名及节点列表在右。 |
| 人体辅助分析 | 真实视频帧和可拖动区域与人体分析设置同页。 | 实际视频帧、区域与分析参数并列；支持画面叠加识别结果。 |
| 片段与时间轴 | 视频画布、时间轴、入点、出点及恢复完整视频均能在同页操作。 | 视频与片段编辑并排，入点和出点直接可调。 |
| 对比选片 | 第一段和第二段选片均显示 A/B 状态；本机素材与外部来源分组。 | 缩略图选择区与外部导入区并列，A/B 状态保留在顶部。 |
| 动作对比 | 两段画面共享播放控制，每段保留独立进度和设同步点入口。 | 双画面与共享播放在主栏；联动、布局、微调与替换在右栏。 |
| 导出设置 | 设置前可读输出范围与视频格式；生成截图、慢放视频与叠加选项沿用真实导出流程。 | 片段封面、范围和格式位于左栏，参数及导出操作位于右栏。 |
| 导出结果 | 结果可预览、保存及分享。截图摘要给出源文件和时间点，视频摘要给出源文件、范围、倍速和帧率。 | 预览与结果摘要、保存、分享及返回设置并列。 |
