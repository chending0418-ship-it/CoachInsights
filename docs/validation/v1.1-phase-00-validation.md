# 1.1 第 00 期验证记录

2026-11-06，分支 `codex/v1.1-toolbox-entry`；工程发布配置保持 1.0.1（4）。本轮由用户授权开发 00 期，并确认三种计数的操作规则，追加模拟比赛历史。用户随后要求按所提供的投球图重设计落点界面。

## 本轮实现

- 打击：滚地／平飞／高飞／挥空；单轮名称、撤销、确认清零、自动恢复、主动保存历史、结束新建、继续编辑及确认删除。
- 投球：捕手视角的固定比例落点图、细线九宫格、本垒板与克制的球场背景；图上手动点击记录归一化位置，好球红色／坏球绿色，编号仅按投球连续累计。外围归入高／低／左／右；点球序进入单球修正，移动点位不自动改判定，不增加球数。牛棚出局独立计数；手机底部固定撤销、出局、保存和本轮选项。
- 比赛：三振／四坏／三出局边界、下一位打者、撤销、恢复，以及用户追加的完整过程历史。工具仍是计数器，不扩展比分或垒包。
- 导航与记录：宽窗口工作室侧栏／窄窗口紧凑入口；新增记录联合作用域筛选、摘要、重开和确认删除。修正团训白板等无 sport 的记录摘要显示。白板隐藏侧栏。
- 图片卡片：固定 1080×1440、完整文本分页、署名日期页码；修改后重新生成、保存全部页、系统分享及取消。00 期示例在 Debug 首页明确标识；P03／P04／P05 尚未提前实现，S02 在线链接仍 Pending。

## 数据与失败保护

新增计数独立使用 `field-tools-v1.json`，不修改 SwiftData 视频快照或 `quick-tools-v1.json`。原子写入成功后才发布新状态；写失败保持原计数并在固定底部显示错误；损坏／未来版本文件保留，禁止空状态覆盖。最近 100 次操作的撤销随本轮保存，包括修正和清零；达到保留边界后停止撤销。旧无 location 的投球点位兼容回退到原分区中心；精确坐标随旋转、布局改变等比显示。

名称使用局部编辑状态再持久化，避免快速输入重绘导致丢末字。相册只请求添加权限；保存时捕获点击瞬间的全部图片快照，后续内容变化不会改变实际保存数量。分享临时目录在取消／结束后清理。

两端合计 83 项通过、0 个未解决失败，1 个 iPhone 上的 iPad 窄窗口用例按设备条件跳过。不同结果包的重复测试不相加；逐项最终证据索引见本机 `summary.json`。

本轮 UI 用例覆盖三种计数、投球地图／纠错弹层／撤销／保存重开、历史筛选／继续编辑／删除；宽屏侧栏收起展开与保留球数、完整地图与底部操作栏同屏；14 页卡片生成、分享取消和相册保存；原视频逐帧／标注／人体分析／关键帧／截图导出、对比入口、窄窗口以及计时、白板和测距不可用提示。

本机新版截图（真实模拟器画面，使用测试录入数据）：`pitch-iphone.png`、`pitch-ipad-studio.png`。后者完整显示本垒板，无需滚动主页面；右侧球序独立滚动。Debug 卡片示例在后续内容工具接入前仅用于公共能力验收。

核心分页测试使用真实渲染图片和系统 OCR，确认长文本最后的 `FINAL TRAINING END` 及末页内容存在；同时验证全部 PNG 文件输出、内容修改后图像变化和超限失败，不把单页图片生成当作长内容完整性证明。

## 迭代与独立审查

subAgent 只读审查发现并已修复：保存失败提示在长过程列表之后不可见；相册异步保存张数读取活动状态；撤销历史耗尽后错误地继续删事件；地图为避免裁切而内缩边缘坐标。最新版固定错误提示、捕获保存快照、保留撤销边界和真实落点中心。

早期结果保留：`iphone-v2`／`ipad-v1` 的外围按钮标识继承、侧栏类型／滚动选择器、示例页底栏遮挡和开关点击问题；用户评审后改为完整落点图。`redesign-iphone` 使用的是后续修正前的产物：发现输入末字丢失和弹层地图选择器命中底层地图。名称状态与选择器已修正。`final-iphone` 的视频分享取消等待与长卡片保存提示可见性问题，已在 `recheck-iphone` 完整通过；`final-ipad`／`recheck-ipad` 的纠错开关位于弹层可视区域外，已缩小纠错地图并滚动至控件可点击，在 `dialog-ipad` 完整通过。`studio-fit-ipad` 再次通过投球完整流程与横屏工作室，确认地图完整容纳。图片页数及保存／失败提示已固定底部。最终只按最新适用结果统计。旧失败结果保留，不作通过证据。

## 保留的验收边界

- 支持 ARKit 的真机实景端点、不同距离与光线下的实际精度；模拟器只验证不支持提示。
- 真机锁屏、静音／专注模式的通知与声音表现。
- 完整视频性能／长时资源测试沿用既有待人工验收状态，本轮不运行 soak 或长测。
- 未新增 Apple Pencil 专项、不增加秒表历史／多计时器等未确认范围。
- P03／P04／P05 真实内容接入及 S02 在线服务不属于 00 期实现。

本轮不递增版本、不触发 GitHub 工作流、不合并、不归档、不打包或上传。原工作区未提交的更名、入口和研究改动保留；本轮实现与验证记录在当前开发分支继续维护。
