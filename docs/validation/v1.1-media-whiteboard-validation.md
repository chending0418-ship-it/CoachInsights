# 视频布局与战术白板改版验证

2026-11-06，`codex/v1.1-toolbox-entry`；发布配置保持 1.0.1（4）。用户要求扩大手机横屏视频、iPad 竖屏上下对比，并参考图片精简白板样式；用户明确更正白板沿用 App 米白／酒红配色。

## 实现

- 手机加载视频后随横屏进入大画布，导航、时间轴和片段设置不再持续挤占画面；浮动工具、播放、逐帧、定位和倍速同屏，时间轴按需打开。提供手动横屏全屏、退出和关闭视频入口。
- 视频分析／对比聚焦时收起工作室侧栏。切换布局不重新加载媒体或重建播放时钟。
- 新对比默认“自动”，竖窗口上下、横窗口左右；手动选择可固定布局。已有记录按保存布局打开，选择“自动”后本次随窗口变化。仍保存实际的上下／左右值，自动模式本身不新增持久化字段。
- 白板使用米白底、酒红细线与圆形球员标记，左侧选择／画笔／撤销／清除，底部防守阵容／跑者／路线。保留拖动、移除、重做、清空确认、自动保存、历史重开和相册导出。
- 增加路线箭头，`BoardStroke.isArrow` 使用可选字段，旧 JSON 缺失时按普通笔画读取；原球员和笔画归一化坐标保持。界面和导出共用 `BoardArtwork`，旧白色笔画及箭头用浅酒红描边保持可见。

## 审查和边界

独立只读审查未发现旧白板数据丢失或坐标转换阻塞；白色箭头头部的可见性问题已补描边。离屏分析页不再继续请求隐藏后续页面的导航／状态栏。

实测修复白板透明标签只有图标／文字可点击的问题：所有工具标签明确完整点击区域。球员拖动改用固定画布坐标、高优先级拖动，并在结束时提交最终位移；两端保留 35×15pt 短拖断言通过。清空与重开测试等待真实界面状态，不只依赖写死的横屏文字。

早期失败结果保留：对比核心夹具曾被相同视频去重，且模拟滑条操作缺少结束拖动；已分别使用不同帧率素材并结束 scrubbing 后重跑通过。iPad 新 UI 测试使用 firstMatch 处理系统弹出菜单重复辅助节点。早期白板触控／短拖失败由上述实现修复后重跑通过；它们不作为最终通过证据。

本轮为布局、操作与持久化的针对性验证；AR 真机精度、真机通知、完整视频性能与长时验收沿用原待验收项。不执行长测、打包、上传或发布。

## 球场边线追加修正

2026-11-06 用户指出白板边线不合理。原外场轮廓单独取点，导致两侧边线未穿过一、三垒，外野弧也过平。现以本垒和内场两条轴统一推导：边线沿本垒—一垒／三垒直线延伸；外野围栏使用同一透视投影下的圆弧，两侧相接。保留原垒包位置、存量笔画与球员坐标，以及 App 米白／酒红配色。

`artifacts/validation/v1.1-board-geometry/` 保留本次构建、导出渲染与双端 UI 证据；iPhone 渲染 1 项、iPhone／iPad 白板流程各 1 项均通过。新截图位于 `artifacts/design/v1.1-board-geometry/`。此前截图保留为迭代记录。
