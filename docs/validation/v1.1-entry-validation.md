## 补充回归与修复

迭代期间同时运行了四项 `StorageTests`，覆盖旧快照读取、持久化重开、引用清理、失败与恢复；两端通过。原视频创建、重命名、导入、旋转、重开、删除流程在 iPhone／iPad 通过；iPad 窄宽窗口往返的播放器检查通过。对应证据分别保留在 `regression`、`deletion-fix` 和 `ipad-final` 输出目录中。

回归发现新增记录列表在数据库对象删除后仍读取旧对象，曾导致删除后退出异常。已将记录行改为值快照、删除前撤下界面引用、忙碌期间不重建记录摘要，并让主入口只加载当前界面；最终删除与返回用例通过。早期失败日志与最终通过结果分开保留。

旧 iPad 用例在视频卡片的合并无障碍标签中直接点击文字，出现不可命中；已改为通过“分析记录”入口选择记录，继续验证同一条记录和帧位置，最终通过。

双端独立对比用例记录过 UIKit `_UIReparentingView` 层级警告，功能断言通过；保留原附件，后续视频界面优化时继续核查。

本轮只验证入口、记录与既有视频流程，不重新评估姿态准确率，不执行长时性能／soak 测试，不触发 GitHub 工作流。
