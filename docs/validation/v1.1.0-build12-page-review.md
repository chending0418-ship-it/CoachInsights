# 棒球训练助手 1.1.0（12）页面复核

iPhone 17 Pro 与 11 英寸 iPad Pro 模拟器从真实工具箱和训练记录入口取图。iPad 使用全屏横向窗口，经典白板在两端均为横屏。独立审核员逐项核对运行截图、原稿、白板基线及对应原生实现。

- 共 45 个产品页面与操作状态，另取投手后方视角，两端各 46 项。设计原型的页面目录用于导航评审。
- 团训计划按原稿样例核对两份计划、四个环节与 35 分钟总时长；教练笔记按同一份长文核对两页分享图。
- 投球按六球四好球核对 67% 和两种教练站位。打击按八棒、比赛按 2 比 1 核对。旧投球坐标的读写和两种视角的点击反算均运行回归测试。
- 视频资料库、选片、绘图、关键帧、人体、裁剪与导出使用本机测试视频。相机与 AR 测距核对设备不可用界面，实拍、瞄准和距离精度需真机验证。

本机可打开[逐页对照图册](../../artifacts/validation/1.1.0-12-a/index.html)和[独立审核记录](../../artifacts/validation/1.1.0-12-a/independent-review.md)。每页可点开原稿和原生图。系统安全区、真实训练内容、当前媒体帧和设备状态会随设备与数据变化。
